SETUP & DEPLOYMENT GUIDE

1. Firebase Setup

Go to Firebase Console, create a project, and enable Authentication (Anonymous / Google) and Cloud Firestore database.

2. Firestore Rules

Ensure your Firestore Security Rules permit artifacts path reads and writes:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /artifacts/{appId}/{document=**} {
      allow read, write: if true;
    }
  }
}

3. GitHub Pages Deployment

Commit this single index.html file to your GitHub repository and activate GitHub Pages from Repository Settings -> Pages -> Deploy from Main Branch.
